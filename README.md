# Shodak

Shodak is a multi-agent AI system for evidence-grounded research and personalized writing.

The system consists of:

- A Research Agent that gathers and evaluates information from authoritative, academic, technical, and community sources.
- A Writer Agent that converts verified research into formats such as blogs, LinkedIn posts, academic writing, and thesis sections.
- An evaluation layer for citation quality, factual grounding, and writing-style consistency.
