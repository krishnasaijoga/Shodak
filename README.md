# Shodak

Shodak is a multi-agent AI system for evidence-grounded research and personalized writing.

## Current Architecture

Shodak is being developed around three core layers:

- Research Agent
- Writer Agent
- Evaluation Layer

The Research Agent will gather information from academic, official, technical, and community sources.

The Writer Agent will convert verified research into formats such as:

- LinkedIn posts
- Blogs
- Academic writing
- Thesis sections

The Evaluation Layer will verify citation quality, factual grounding, output format, and writing-style consistency.
